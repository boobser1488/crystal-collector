# Crystal Collector

Небольшая аркада на Rust и Macroquad: управляйте корзиной и ловите падающие красные кристаллы в пещере. Каждый пойманный кристалл приносит одно очко.

**Управление:** W, A, S, D — движение корзины.

## Запуск

Установите Rust и выполните из корня репозитория:

```sh
cargo run --release --locked
```
